# Kubernetes Foundation Manifests

This repository is organized by Kubernetes resource type:

- `common/` - shared namespace, service accounts, and common objects
- `pods/` - Pod manifests
- `deployments/` - Deployment manifests
- `services/` - Service manifests
- `configmaps/` - ConfigMap manifests
- `secrets/` - Secret manifests
- `storage/` - PVC and storage-related manifests
- `ingress/` - Ingress manifests

Each folder contains a `manifests/` directory for YAML files.
